# Overrides ledger

Root `package.json` `overrides` starts empty. Every future pin gets an entry
here with its rationale and revisit trigger (NAV-001, Disciplines) — JSON
cannot carry comments, so this ledger is the comment. An override that
outlives its advisory becomes silent version skew; each entry names when it
can go.
